# Bob Client Bobathon - Detailed Agenda (Seller Edition)

## Overview
**Duration:** Flexible (3, 4, or 6 hours) - **3-4 hours recommended for sellers**
**Format:** Self-serve or facilitated delivery
**Target Audience:** Software engineers, tech leads, and developers

## Delivery Options

### Self-Serve Delivery
- Client runs bobathon independently using provided materials
- Comprehensive instructions and troubleshooting guides included
- Email support from seller
- Survey for feedback collection

### Facilitated Delivery
- Seller provides virtual facilitation
- Live demonstrations and real-time Q&A
- Interactive labs with seller guidance

## 📝 Facilitator Notes

### Preparation Checklist
- [ ] Review client's bobathon-config.yaml
- [ ] Customize labs based on client use cases
- [ ] Test all lab exercises in client environment
- [ ] Prepare backup examples for common issues
- [ ] Set up communication channels (Slack, Teams, etc.)
- [ ] Prepare feedback forms
- [ ] Test screen sharing and demo setup

### Tips for Success
1. **Start with quick wins** - Begin with simple, impressive examples
2. **Encourage questions** - Create a safe learning environment
3. **Be flexible** - Adjust pace based on participant needs
4. **Use real examples** - Relate everything to client's actual work
5. **Celebrate progress** - Acknowledge achievements throughout the day
6. **Provide context** - Explain the "why" behind best practices
7. **Follow up** - Schedule office hours and check-ins

### Common Challenges
- **Varying skill levels** - Pair experienced with less experienced participants
- **Technical issues** - Have backup plans and troubleshooting guides ready
- **Time management** - Use timers and be prepared to adjust on the fly
- **Engagement** - Use interactive elements and frequent breaks
- **Complex use cases** - Break down into smaller, manageable pieces

## 🔄 Customization Options

### Half-Day Format (3 hours)
- Compress intro to 15 minutes
- Focus on basic features (45 min)
- One advanced topic (30 min)
- Client-specific lab (60 min)
- Wrap-up (15 min)

### Two-Day Format (12 hours)
- Day 1: Deep dive into Bob features with extensive practice
- Day 2: Full day on client-specific implementation and advanced topics

### Virtual Format Adjustments
- Add 15-minute breaks every 90 minutes
- Use breakout rooms for lab exercises
- Provide pre-recorded demos as backup
- Use collaborative tools (Miro, Mural) for engagement
